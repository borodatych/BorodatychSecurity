# CLAUDE.md

Общие правила — в глобальном `~/.claude/CLAUDE.md` и `~/.claude/rules/`, здесь только специфика

## Что это

Borodatych Security — проверка защиты сервера и сайта: открытый CLI и MCP для агентов, позже сайт security.borodatych.ru
Замысел — [docs/idea.md](docs/idea.md), список проверок — [docs/checks.md](docs/checks.md), план — [docs/roadmap.md](docs/roadmap.md)

## Проверки перед сдачей

```bash
bun run check   # типы и линт
bun test        # тесты
bun run build   # сборка пакета в dist/
```

## Что важно знать

- CLI только читает: ничего на сервере не меняет, не ставит и не перезапускает — это обещание пользователю
- Каждая проверка — отдельный модуль с id из docs/checks.md; список проверок и docs/checks.md не расходятся (тест)
- Команды системы зовутся через один исполнитель с таймаутом; нет команды или прав — проверка «не проверить», а не «провал»
- Тексты отчёта — русские, в каталоге строк; в коде литералов текста нет
- Секреты в отчёт не попадают: значения из .env, ключи и пароли не печатаются никогда
