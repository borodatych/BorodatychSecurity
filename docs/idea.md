# BORODATYCH SECURITY

## 1. Зачем

Владелец сайта, собранного с ИИ, выкатывает сервер и не знает, что у него открыто наружу
Мануалы есть: «Чек-лист перед продакшеном» и «Эшелон» студии ART Aristocrat — но проходить их надо руками
Нужен инструмент, который сам пройдёт проверки, скажет по-русски, что сломано и чем чинить, а агент по отчёту починит

---

## 2. Три части

**CLI** — запускается на сервере одной строкой (`npx @borodatych/security`), по умолчанию только читает, отчёт текстом и JSON; отдельная команда `fix` чинит после диффа и согласия
**MCP** — тот же CLI как инструменты для агента (Claude Code, VibeIDE, VibeIDEA): агент проверяет и чинит сам
**Сайт** security.borodatych.ru — проверка снаружи по домену, ночное слежение, история, оповещения — позже, когда CLI начнут ставить

Почему не start0: первая часть — npm-пакет без веба, пак ей не нужен; сайт, когда до него дойдёт, — на start0
Снаружи сайт переиспользует движок Штрафометра: очередь проверок, Playwright, отчёт, оплата, кабинет

---

## 3. Чем отличаемся

Бесплатные проверки снаружи есть (Mozilla Observatory, securityheaders.com), изнутри — Lynis
Наше: русский отчёт «что сломано → чем чинить», проверки под стек вайб-кодера (Docker, Caddy, NPM, Bun, Node, Supabase), агент чинит сам через MCP, слежение с оповещением в Telegram

---

## 4. Деньги

По принципу владельца: людям бесплатно, с тех, кто зарабатывает, — копеечку
Бесплатно: CLI и MCP целиком, код открыт; разовая проверка снаружи
Подписка: ночная проверка и оповещение, когда что-то открылось; история; несколько серверов; PDF-отчёт для заказчика — студиям и фрилансерам
Разово: «настроим за вас» — партнёрство с теми, кто это продаёт
